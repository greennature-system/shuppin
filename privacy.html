プライバシーポリシー

出品管理ツール（Greennature 社内用）／ 2026年10月5日 制定

1. このポリシーの対象

Greennature（以下「運営者」）が社内で使う「出品管理ツール」（以下「本ツール」）で扱う情報について定めます。本ツールは運営者の従業員だけが使う社内向けのツールです。

2. 扱う情報

  • 従業員が登録する商品の写真・状態・メモ・担当者名
  • ヤフオク!の取引に関する情報（オークションID、落札金額、送り状番号など）
  • 本ツールを使う Google アカウントのメールアドレス（ログインの確認のため）

3. 使い方

扱う情報は、出品・発送・売上の管理という社内の業務のためだけに使います。広告や、業務と関係のない目的には使いません。

4. 保存する場所

情報は、運営者の Google アカウントの Google スプレッドシートと Google ドライブに保存します。

5. 外部のサービスへの送信

  • 商品のタイトル・説明文を作るため、商品の写真とメモを Google の Gemini API に送ります。
  • 発送の状況を確かめるため、送り状番号をヤマト運輸の荷物お問い合わせに送ります。

上記のほかに、扱う情報を第三者に提供・販売することはありません（法令に基づく場合を除きます）。

6. Google のユーザーデータの扱い

本ツールが Google API から受け取る情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

7. 削除

不要になった写真は自動でゴミ箱に移します。情報の削除を希望する場合は、下のお問い合わせ先にご連絡ください。

8. お問い合わせ

greennature.system@gmail.com
